# Происхождение кода

Мини-приложение выделено по запросу владельца из [Вектора](https://github.com/ignorov3-maker/vektor-math-lab), снимок `24df3ed092ee2808a8caedb703239eaeaaa3f580`.

- `js/topics.js`: помощники, девять генераторов и сообщения о типичных ошибках из `content/fractions.js`. Убраны методички, маршрут освоения и повторения.
- `js/check.js`: основа из `content/check.js`. Добавлены точное сравнение рациональных чисел через BigInt, ограничения ввода и сообщения для единого текстового поля.
- `index.html`, `style.css`, `icon.svg`, `js/app.js`, `js/session.js`, сервер и тесты созданы для мини-приложения.

Сохранены темы и учебные правила исходника: равные дроби принимаются, для сокращения нужна несократимая дробь, в заданиях на смешанные числа важна форма записи. Заимствованы фирменные цвета Вектора.

Лицензия в исходном репозитории не обнаружена. Новая открытая лицензия на заимствованный код не назначается.
