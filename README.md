# Вектор мини — проверка ответов по дробям

Небольшой учебный проект по информатике: ученик выбирает тему, решает четыре задания и получает результат. Зачёт — от трёх верных ответов. Проверяет ответы JavaScript в браузере. Работает без регистрации, сервера, базы данных, ИИ и внешних библиотек.

## Запуск

Скачайте репозиторий и откройте `index.html` двойным щелчком. Интернет не нужен. Подходит для современного Chrome, Edge, Firefox или Safari с поддержкой BigInt.

Необязательный запуск через Node.js 18 или новее:

```sh
npm start
```

Откройте `http://127.0.0.1:4173`. Устанавливать зависимости не нужно.

## Возможности

- Девять тем: доли, сокращение, сравнение, сложение и вычитание с одинаковыми и разными знаменателями, смешанные числа, умножение, деление, часть и целое.
- Три уровня сложности. Числа генерируются заново для каждой проверки.
- Запись ответа: `3/4`, `2 1/3`, `5`, `<`, `>` или `=`.
- Один засчитываемый ответ на задание. После него можно посмотреть разбор ошибки и перейти дальше.
- Пустой или нечитаемый ответ, включая знаменатель 0, не тратит попытку. Верное значение в неподходящей форме считается ошибкой записи: например, `6/8` в задании на полное сокращение.
- Итог из четырёх баллов и возможность пройти проверку ещё раз.
- Адаптация для телефона и управление с клавиатуры: Enter проверяет ответ, затем Enter переводит к следующему заданию.

Прогресс живёт только в текущей вкладке и сбрасывается при обновлении. «Начать заново» сразу начинает новую попытку. Ответы находятся в браузере: это тренажёр для самопроверки, а не защищённая контрольная работа.

## Алгоритм для защиты проекта

1. Пользователь выбирает тему и сложность.
2. Генератор создаёт четыре задания с условиями и эталонными ответами.
3. Программа читает введённый текст: целое, дробь, смешанное число или знак.
4. Для дробей и чисел получает точные целые числитель `n` и знаменатель `d`.
5. Сравнивает два значения перекрёстным умножением: `n1 * d2 === n2 * d1`. Используется BigInt, поэтому близкие значения не принимаются из-за округления.
6. Дополнительно проверяет формат, который просит задание: сокращённую дробь, неправильную дробь или смешанное число.
7. Показывает результат, при ошибке — объяснение. После четырёх заданий считает верные ответы.

Пример: для `1/2` и `2/4` произведения равны: `1 × 4 = 2 × 2`. Но если условие требует сократить дробь, `2/4` не принимается: НОД(2, 4) равен 2.

Для защиты можно объяснить массивы (темы и ответы), объекты (задание), функции (генерация и проверка), условия (верно/неверно), циклы, события формы и алгоритм Евклида для НОД.
